## Что изменилось

Результат поиска теперь можно прочитать сразу: **одна строка — одна раскладка**, и по ней видно, фантом это или рабочая раскладка.

### Понятный список раскладок (FIX-34)

Windows хранит одну и ту же раскладку в разных форматах: `00000419` в `Preload` и `68748313` (HKL `0x04190419`) в CTF. Прежний сканер показывал каждую форму отдельной строкой, из-за чего на компьютере с двумя раскладками список насчитывал пять строк, а две из них назывались `Layout (04090409)` и `Layout (04190419)` — слово выглядело названием раскладки, но им не являлось.

- Ключ строки — канонический KLID, поэтому раскладка одна, сколько бы записей Windows ни оставила.
- Настоящее имя берётся из каталога Windows: запись `04070407` теперь называется `German (00000407)`, а не `Layout (04070407)`.
- **Ничего не потеряно:** исходный код каждой записи сохранён и показан в подробностях («В реестре: 00000419, 68748313»), а сама запись остаётся видна по своему точному адресу в реестре.
- Объединение не обещает лишнего: удаление по коду раскладки находит и записи HKL — раньше план по `00000419` такие записи не видел.
- Фантомы вида `d001dead` не сворачиваются и сохраняют имя.

### Метка состояния у каждой строки

| Метка | Что означает |
|---|---|
| `в списке языков` | Раскладка установлена и используется |
| `похоже на кеш активной раскладки` | Записи только в CTF, но язык активен: Windows пересоздаст кеш сам |
| `только в кеше CTF — вероятный остаток` | Языка в списке нет, записи остались лишь в кеше: вероятный фантом |
| `в настройках, но не переключается` | Прописана в реестре, но `GetKeyboardLayoutList` её не показывает |

Если состояние сессии прочитать не удалось, метка не превращается в диагноз: приложение говорит «не прочитано», а не «всё сломано».

### Хеши релиза публикуются автоматически (FIX-33)

Раньше SHA256 в README и в описании релиза вписывался руками — то есть переставал совпадать ровно тогда, когда он нужен. Теперь скрипт `scripts/release_hashes.py` считает хеш архива и EXE внутри него и подставляет таблицу между маркерами в README, а также публикует `SHA256SUMS.txt` и таблицу в описание релиза. Хеш EXE считается отдельно: онлайн-сканеры портативный архив не берут.
